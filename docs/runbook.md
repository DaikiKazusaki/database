# 障害対応

「動かない」と言われたときに，上から順に見ていくための手引き．

まず確認する場所：

- Vercel のダッシュボード > Deployments（最新のデプロイが成功しているか）
- Vercel のダッシュボード > Logs（サーバー側のエラー）
- Neon のダッシュボード（プロジェクトが動いているか）

## 症状別

### 全ページで500が返る／「Basic認証の環境変数が設定されていません」と出る

`BASIC_AUTH_USER` か `BASIC_AUTH_PASSWORD` が未設定．
Vercel の環境変数を確認し，直したら**再デプロイする**（環境変数を変えただけでは反映されない）．

### 認証ダイアログが何度出しても通らない

入力しているパスワードが古い．年度替わりに更新している（[handover.md](handover.md) 参照）．
パスワードマネージャの値を確認する．

### 棋譜の一覧・検索だけが「棋譜の取得に失敗しました．」になる

DBに繋がっていない．次の順に疑う．

1. Neon のプロジェクトが停止・削除されていないか（無料プランは放置すると止まることがある）
2. `DATABASE_URL` が失効していないか．Neonでパスワードをローテートすると変わる
3. Vercel の環境変数に反映されているか

`npm run backup` が手元で通るかを試すと，アプリ側の問題かDB側の問題かを切り分けられる．

### 棋譜再生の盤が表示されない（他は正常）

再生盤は `app/components/KifuPlayer.tsx` から
`https://cdn.jsdelivr.net/npm/shogi-player@1.1.24` を実行時に読み込んでいる．
このCDNが落ちているか，ネットワーク側で遮断されている可能性が高い．
ブラウザの開発者ツール > Network で，そのリクエストが失敗していないか見る．

依存が `package.json` に入っていないため，CDN側の都合で消えると復旧手段がない．
自前配信への切り替えは保守レビューで「今学期」の課題としている．

### 棋譜を登録できない

画面に出ているエラー文をそのまま読む．`app/lib/gameValidation.ts` のメッセージが直接表示される．

- 「同じ棋譜が既に登録されています」→ 重複防止が働いている．正常な挙動
- 「KIF形式の棋譜として読み取れません」→ 指し手の行が見つからない．KIF以外の形式（CSA・USIなど）を貼っていないか
- 「次の項目が入力されていません」→ 棋譜のヘッダーから読み取れなかった項目がある．手で埋める

### 対局日が1日ずれて見える

`date` は日付だけの列だが，一覧の表示は閲覧者のタイムゾーンで再変換されている．
日本以外から見ていると前日が表示されることがある．詳細は README の「データベース」節．

## よくある操作

### 削除した棋譜を戻す

削除は論理削除なので，データは残っている．

```sql
UPDATE games SET deleted_at = NULL WHERE id = ...;
```

### バックアップから復元する

```bash
npm run restore -- backup/games-2026-08-29.json        # 何件戻るかを表示するだけ
npm run restore -- backup/games-2026-08-29.json --yes  # 実際に書き戻す
```

既存の行は上書きせず，DBに無いものだけを入れる．

日次バックアップは GitHub の Actions タブ >「棋譜の日次バックアップ」から成果物をダウンロードできる（90日で消える）．
手元で取りたいときは `npm run backup`．

### 棋譜がまとめて消えたとき

1. **まず何もせず，`npm run backup` で現状を保存する**（壊れた状態も証拠として残す）
2. 直前のバックアップをダウンロードする
3. 上の手順で復元する
4. 何が起きたのかを [handover.md](handover.md) に書き残す
